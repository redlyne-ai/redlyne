# Code of Conduct

The Redlyne project adopts the **Contributor Covenant**, version 2.1, as its code of conduct.

The full text is published and maintained at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Everyone participating in the Redlyne community — issues, discussions, pull requests, code review, social channels, conferences — is expected to read it and act accordingly.

## Scope

This Code of Conduct applies within all project spaces, and also applies when an individual is officially representing the project or its community in public spaces.

## Reporting

If you experience or witness behavior that does not align with the Contributor Covenant, please report it privately to the maintainers via:

- Email: **conduct@redlyne.io**

All reports will be reviewed and investigated promptly and fairly. The maintainers are obligated to respect the privacy and security of the reporter of any incident.

## Enforcement

Maintainers will follow the **Enforcement Guidelines** described in the Contributor Covenant 2.1 to determine the consequences of any action they deem in violation of this Code of Conduct. The four-level ladder (Correction → Warning → Temporary Ban → Permanent Ban) applies.
